# Excel Files

Place transaction reconciliation .xlsx files here.

Required columns:
  PAN                    — masked card number (e.g. 412345******7890)
  RETRIEVAL_REFERENCE_NR — 12-digit transaction RRN

Additional columns supported:
  REFERENCE_DATE, POST_TRAN_ID, Card Scheme, TERMINAL_ID,
  CARD_ACCEPTOR_NAME_LOC, FROM_ACCOUNT_ID, TRANS_AMT, BANK, ACQRRN
