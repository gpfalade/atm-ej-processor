# Output Folder

PDF files are generated here automatically when journal_split.py runs.
Organised into subfolders by card BIN (first 6 digits of PAN).

Example:
  output_folder/
    412345/
      412345_001234567890_143022_20230713.pdf
      412345_001234567891_151045_20230713.pdf
    523456/
      523456_009876543210_091230_20230714.pdf
